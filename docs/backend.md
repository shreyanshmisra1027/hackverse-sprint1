# Stock Analysis Backend

## Overview
Backend service for AI-powered stock analysis using Google Gemini agents.

## Agents
- **Technical Agent**: Analyzes stock technical indicators
- **Sentiment Agent**: Analyzes news sentiment
- **Filings Agent**: Analyzes SEC filings and documents
- **Synthesis Agent**: Combines all analyses for final recommendation
